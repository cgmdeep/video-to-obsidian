# 陌生用户首次使用验收

本清单只验证 `v0.1.0-alpha.10` 尚未被现有证据完整覆盖的最后一段：一个没有作者旧配置的普通 Windows 用户，能否从生产官网开始，仅依靠图形界面和官方扫码，完成微信提交并在 Obsidian 看见正式笔记。

它不是全量回归。安装/修复/卸载生命周期、按钮合同、双平台真实样本、质量固定集、排队与故障恢复已经有独立证据，本轮不机械重跑。

## 时间盒上线闸门

为保证产品尽快进入录制和公开 Alpha，本轮先执行最短可信路径：完成 A 的全部免费步骤，再执行 B 的第 4、5、6、7 步，用一条 15–30 分钟 B站视频验证首次入库、缓存复用和 Vault 一致性。该路径通过后即可冻结 `alpha.10`，停止新增功能并进入录制准备。

抖音陌生账户首条真实任务以及 B 的第 1、2、3 步改为上线后补充，不阻塞本次冻结；此前的抖音真实闭环只作为既有平台证据。未执行时不得声称“本轮双平台陌生用户路径通过”。

## 验收边界

- 使用 Windows 11 的新本地用户、全新虚拟机或没有安装过视知库的设备；
- 从 <https://shizhiku.cn/download> 下载，不使用开发目录、临时 Artifact 或维护者复制的安装包；
- 目标安装包为 `v0.1.0-alpha.10`；正式字节数与 SHA-256 以匹配标签 Release 的 `SHA256SUMS` 为准；
- 使用标准版：逐字稿关闭、原视频不保存、K2.7；
- 用户只亲自处理 Kimi Key、抖音/B站扫码和 ZCode 官方微信 Bot Channel 扫码；
- AI 助手可以观察状态、收集脱敏报告和排错，但不得读取 Key、Cookie、验证码、浏览器数据库或签名媒体 URL；
- 真实视频分析前单独确认费用。本轮免费阶段不得调用 Kimi 视频分析。

## A. 免费阶段

1. 从生产官网下载安装器，记录浏览器完成下载；核对文件大小和 SHA-256。
2. 双击安装器，保持标准版，不打开源码仓库或终端；完成“安装 / 修复本机”。
3. 确认界面能打开 Obsidian、抖音登录、B站登录和 ZCode 工作区；不要求用户理解 Python、MCP 或 Cookie 文件。
4. 用户在安装器内输入自己的 Kimi Key；不得通过聊天、截图或普通文本传递。
5. 用户分别在专用 `VideoToObsidian` Firefox Profile 中扫码登录抖音和B站。
6. 用户打开 `文档\视知库助手`，在 ZCode 官方 Bot Channel 中扫码连接自己的微信。
7. 在微信发送“检查系统”。预期：只调用一次 `doctor`，回复所有必需项已就绪，且不产生视频分析费用。
8. 点击“导出脱敏诊断报告”。预期：报告显示 `ready_for_free_bot_test=true`、`contains_secrets=false`、`contains_local_paths=false`、`paid_call_performed=false`。

任何一步失败都先停止；保留脱敏报告和错误码，不用真实视频试探环境，也不反复重装。

## B. 单次付费闭环

只有用户明确批准本轮费用后继续。

1. 微信发送一条普通抖音单视频分享文本。
2. 预期只调用一次 `analyze_douyin`，回复包含稳定身份、正式笔记路径、`video_analysis_usage` 和是否缓存；`zcode_routing_usage` 不可用时如实标记，不猜测为零。
3. 用 Obsidian 打开安装器登记的 Vault，肉眼确认刚生成的正式笔记可见、正文完整、来源链接正确。
4. 微信发送一条 15–30 分钟的普通 B站单视频分享文本。
5. 预期只调用一次 `analyze_bilibili`，并在 `Bilibili/` 中看到正式笔记。
6. 原样再次发送其中一条已经成功的分享文本。预期返回完成态缓存，不新增 Kimi 视频分析，不产生第二份正式笔记。
7. 运行只读 Vault 审计。预期：`duplicate_groups` 为空、`unreadable_files=0`。

若费用预算只允许一条真实视频，优先选择 15–30 分钟 B站样本，并保留之前已经通过的抖音真实闭环作为平台证据；不得把未运行的一侧写成本轮通过。

## C. 必须记录的证据

- Windows 版本和环境类型（新用户、虚拟机或新设备）；
- 官网 URL、安装器版本、字节数和 SHA-256；
- 免费诊断报告中的布尔状态，不复制本机路径；
- 用户确认“微信收到回复、Obsidian 看见笔记”的时间；
- 每条真实分析的工具名、稳定身份、是否缓存、`video_analysis_usage` 和估算费用；
- 重复提交前后的受管笔记数量、重复来源组和 Kimi 调用次数；
- 失败时的稳定错误码、失败步骤和是否可恢复；
- 清理结果：默认不保存原视频，缓存、日志和诊断中不出现 Secret。

## 通过标准

只有以下条件同时满足，才可以把 P1/P5 的陌生用户闭环标为完成：

- 用户不需要开发者远程编辑配置或运行源码命令；
- 免费阶段全部通过；
- 至少一条用户批准的真实视频从微信进入并在 Obsidian 中可见；
- 重复提交不重复付费、不生成重复正式笔记；
- 证据不包含 Key、Cookie、验证码、浏览器数据库、签名媒体 URL或可识别本机路径；
- 所有失败都如实显示，没有把部分成功报告为完整入库。

抖音和B站各一条都通过时，才可以声称本轮双平台陌生用户路径通过；仅一条通过时只能记录对应平台。
