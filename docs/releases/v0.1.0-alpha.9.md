# 视知库 v0.1.0-alpha.9

这是面向公开下载的 Windows x64 首装依赖修复版技术预览。它继续验证“微信发送抖音/B站单视频链接，在用户自己的电脑上生成结构化 Markdown 并写入 Obsidian”的本地优先链路。它不是稳定版、托管服务或公共微信机器人。

## 本版修复

- Windows 依赖安装全部显式限定到 `winget` 社区源，不再因为不可用或证书异常的 Microsoft Store 源阻断 Python、Firefox 或 ffmpeg；
- 已经能正常执行的 `ffmpeg` 与 `ffprobe` 会直接复用，不再要求其必须由某个特定 winget 包登记；
- Obsidian 优先复用现有桌面安装；缺失时使用明确的 `winget` 源，失败后从 Obsidian 官方发行地址降级下载，不再依赖 `msstore`；
- 保留 `alpha.8` 的 Vault 登记、隔离 Firefox Profile、ZCode 专用工作区、脱敏诊断和费用边界修复。

## 验收证据

- 跨平台核心测试覆盖首次分析、缓存命中、Kimi 失败、费用归属、受管 ZCode 规则和 Windows 依赖源合同；
- 发布流水线将在干净 Windows Runner 从单文件安装器执行首次准备、真实按钮动作、原地修复、默认卸载、重装和受管私有目录卸载；
- 自动安装、体检和本轮发布验收不调用付费模型，也不输出 Key、Cookie、Bearer、签名媒体地址或本机路径；
- XOS 实机复现了 `msstore` 证书异常，证明旧版没有显式锁定源时会错误阻断已经具备 ffmpeg 的机器，本版按该真实故障修复。

## 已知限制

- 安装包尚未代码签名，Windows SmartScreen 可能显示“未知发布者”；
- 首次准备仍需联网下载依赖，建议预留约 1–2 GB 空间和 10–30 分钟；
- 用户必须亲自在专用 Firefox Profile 中扫码登录抖音和B站，并在 ZCode 官方 Bot Channel 中连接自己的微信；
- 自动合同不能替代真人确认平台会话、ZCode Bot Channel 或首篇业务笔记；
- 逐字稿增强版尚未完成真实视频全链路验收，公开默认仍是不需要 SenseVoice 的标准版；
- 戏仿、夸张和反问尚未分别冻结质量样本；20 人体验、真实平台登录失效和付费服务中断的长时间验收仍未完成；
- 仅支持抖音/B站普通单视频，不支持合集、直播、番剧、互动视频或 DRM 内容。

## 安全提示

只使用自己的 Kimi Key 与平台账号。不要向 Issue、聊天截图或日志粘贴 Key、Cookie、Bearer 或签名媒体地址。下载后请核对同一 Release 中的 `SHA256SUMS`。
