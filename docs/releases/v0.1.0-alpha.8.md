# 视知库 v0.1.0-alpha.8

这是面向公开下载的 Windows x64 首次使用修复版技术预览。它继续验证“微信发送抖音/B站单视频链接，在用户自己的电脑上生成结构化 Markdown 并写入 Obsidian”的本地优先链路。它不是稳定版、托管服务或公共微信机器人。

## 本版修复

- “用 Obsidian 打开”会先把安装器创建的目录安全登记为 Vault，再按 Vault ID 唤起 Obsidian；不再把未登记目录错误地当成 `path` 参数；
- 登记前保留用户已有 Vault 和未知配置字段，创建恢复副本，并在配置损坏或并发修改时拒绝覆盖；
- “登录抖音”和“登录B站”分别打开隔离的 `VideoToObsidian` Firefox Profile；
- “用 ZCode 打开视知库助手”把受管工作区作为启动参数交给已安装 ZCode，仍保留手动复制路径的降级入口；
- 诊断导出、工作区复制、Obsidian、ZCode 和双平台启动动作进入干净 Windows 图形按钮验收；
- 分析结果新增 `video_analysis_usage`、缓存标志和明确的 usage 归属；ZCode 路由 usage 不在 MCP 工具边界内，不再和视频分析费用混算或假定为零。

## 验收证据

- 跨平台核心测试覆盖首次分析、缓存命中、Kimi 失败、费用归属和受管 ZCode 规则；
- 干净 Windows Runner 从单文件安装器完成首次准备、真实按钮动作、原地修复、默认卸载、重装和受管私有目录卸载；
- Obsidian 合同核验 Vault 登记、原配置保留和恢复副本；ZCode 合同核验受管工作区启动参数；
- ROG Windows 11 原地修复保留现有配置，更新受管工作区规则后 ZCode 继续运行；真实 Vault 审计为 0 个重复组和 0 个不可读文件；
- 自动安装、体检和本轮发布验收不调用付费模型，也不输出 Key、Cookie、Bearer、签名媒体地址或本机路径。

## 已知限制

- 安装包尚未代码签名，Windows SmartScreen 可能显示“未知发布者”；
- 首次准备仍需联网下载依赖，建议预留约 1–2 GB 空间和 10–30 分钟；
- 用户必须亲自在专用 Firefox Profile 中扫码登录抖音和B站，并在 ZCode 官方 Bot Channel 中连接自己的微信；
- 自动合同能证明按钮正确启动目标并传入工作区，不能替代真人确认平台会话、ZCode Bot Channel 或首篇业务笔记；
- 逐字稿增强版尚未完成真实视频全链路验收，公开默认仍是不需要 SenseVoice 的标准版；
- 戏仿、夸张和反问尚未分别冻结质量样本；20 人体验、真实平台登录失效和付费服务中断的长时间验收仍未完成；
- 仅支持抖音/B站普通单视频，不支持合集、直播、番剧、互动视频或 DRM 内容。

## 安全提示

只使用自己的 Kimi Key 与平台账号。不要向 Issue、聊天截图或日志粘贴 Key、Cookie、Bearer 或签名媒体地址。下载后请核对同一 Release 中的 `SHA256SUMS`。

安装、扫码、首次体检与失败恢复参见 [Windows 安装与扫码指南](https://github.com/cgmdeep/video-to-obsidian/blob/v0.1.0-alpha.8/docs/INSTALL_WINDOWS.md)。
