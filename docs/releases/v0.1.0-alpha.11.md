# 视知库 v0.1.0-alpha.11

`v0.1.0-alpha.11` 是 Windows x64 未签名公开 Alpha，只修复首次配置后的两个真实图形阻塞。

## 修复

- 登记新 Obsidian Vault 前先请求正在运行的 Obsidian 正常退出；5 秒后仍有残留进程才结束进程树，完成安全登记后重新启动目标 Vault。
- ZCode 不再把工作区目录作为无标记参数传入，而是使用当前桌面端要求的 `--open-workspace <目录>`，确保“视知库助手”被加载为真正的项目工作区。
- 安装器明确提示首次登记会重启 Obsidian；若自动动作失败，仍保留手动重试入口，不回滚已经完成的本机准备。

## 保持不变

- 延续 `alpha.10` 的配置完成后自动打开动作，以及 `alpha.9` 对故障 Microsoft Store 源的隔离。
- 默认不保存原视频、不生成逐字稿；Kimi Key 只保存在 Windows Credential Manager。
- 不包含 Cookie、API Key、私人笔记或作者环境数据。

## 已知限制

- 安装包尚未进行商业代码签名，Windows SmartScreen 可能提示。
- ZCode、Kimi 和视频平台均使用用户自己的账号；电脑与 ZCode 需要保持运行。
- macOS 公开包、托管机器人、支付和网页任务中心不属于本次 Windows Alpha。
