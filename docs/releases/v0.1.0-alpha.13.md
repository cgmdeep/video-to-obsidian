# 视知库 v0.1.0-alpha.13

本版是 `alpha.12` 知识激活助手的 Windows 热修复版。

## 修复

- 强制本机核心的标准输入、标准输出和错误输出使用 UTF-8，修复中文 Windows 上请求被系统代码页错误解码、返回乱码并提示 JSON 无效的问题；
- 知识激活侧栏在窄宽度下禁止横向溢出，长笔记标题使用省略显示；
- 操作按钮和分析强度改为安全换行，标题、提示、状态和底部说明可在窄侧栏内自动折行；
- 本机核心返回非 JSON 内容时显示可操作的修复提示，不再把底层解析错误直接暴露给用户。

## 安全与边界

- 没有改变模型、费用、来源笔记数量或 API Key 存储方式；
- 每次点击仍最多发起一次知识生成调用；
- 本版仍是未签名 Windows x64 Alpha，首次运行可能出现 SmartScreen 提示。
