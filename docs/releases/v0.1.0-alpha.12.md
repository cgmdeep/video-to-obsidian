# 视知库 v0.1.0-alpha.12

本版在 `alpha.11` 已通过的 Vault 登记和 ZCode 工作区启动基础上，补齐 Obsidian 内的本机“知识激活”助手。

## 新增

- Windows 安装器自动向所选 Vault 安装并启用 `视知库·知识激活` Obsidian 插件；
- Obsidian 右侧边栏支持提问、两篇对比、知识卡和行动清单；
- 插件直接调用本机视知库核心，从 Windows 凭据管理器读取用户自己的 Kimi Key，不需要旧云端绑定码或常驻服务；
- 只在用户点击“生成衍生知识”后发起一次付费模型调用，结果另存为新 Markdown，不覆盖来源笔记；
- 安装包自检和 Windows 干净环境验收新增插件资源、启用列表及修复幂等性检查。

## 安全与边界

- 笔记内容被当作资料而非指令，并有明确的来源数量与长度上限；
- 插件不保存或显示 API Key，不使用旧云端 Obsidian 同步接口；
- 本版仍是未签名 Windows x64 Alpha；首次运行可能出现 SmartScreen 提示。

## 发布闸门

正式切换官网前，必须先通过标签 CI、干净 Windows 安装/修复/卸载生命周期，xos 图形首装和一次用户明确批准的真实知识生成。
