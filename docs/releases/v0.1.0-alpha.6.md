# 视知库 v0.1.0-alpha.6

这是面向公开下载的 Windows x64 技术预览版。它继续验证“微信发送抖音/B站单视频链接，在用户自己的电脑上生成结构化 Markdown 并写入 Obsidian”的本地优先链路。它不是稳定版、托管服务或公共微信机器人。

## 本版改进

- 按稳定来源身份统一检查 Vault 根目录与平台子目录，防止老版笔记与新版布局同时存在时静默生成重复正式笔记；
- 在下载和 Kimi 之前阻断已有正式笔记冲突，偏好变更或明确启用 K3 时只生成 Vault 外候选稿，不覆盖旧笔记；
- 强化下载、时间线代理和逐字稿检查点复用，Kimi 失败后由人工重试不再重复已完成的前置步骤；
- 增加 1 GiB 检查点盘空间前置闸门，低磁盘空间时在下载和付费调用前停止；
- 收紧排队、失败回执和重试边界，未知异常不向 ZCode 暴露底层错误正文，平台降级和 Kimi 人工重试不再被混为无界重试；
- 安装器增加标准版/逐字稿增强版受管切换，只修改本项目档位字段并保留自定义 Vault、未来字段和文件换行格式；
- 安装器现在可检测已安装 ZCode，直接打开应用或传入专用“视知库助手”工作区；未安装时才跳转官方说明；
- 新增有界的脱敏支持报告，只包含检查状态与后续动作，不包含用户名、本机路径、Key、Cookie、Bearer 或签名媒体地址。

## 验收证据

- 111 项核心自动测试通过，覆盖 100 个无付费同时提交的单节点排队固定集；
- Windows/Linux、Python 3.11/3.12 CI，安全扫描和 Windows 单文件安装器构建通过；
- ROG Windows 11 实机完成原地修复、Vault/工作区复用、内置载荷校验和脱敏支持报告扫描，未调用付费模型；
- 抖音小视频、B站约 20 分钟典型视频和 37 分钟长视频均完成真实下载、K2.7 单次分析、Obsidian 入库和临时媒体清理；
- 多说话人、反讽/引用、音画数字冲突与偏好优先级完成 3 次有界付费固定集验收；
- B站完成态缓存完成 30 轮、每轮间隔 60 秒的零新增 Kimi 调用巡检。

## 已知限制

- 安装包尚未代码签名，Windows SmartScreen 可能显示“未知发布者”；
- 首次准备仍需联网下载依赖，建议预留约 1–2 GB 空间和 10–30 分钟；
- 用户必须亲自在专用 Firefox Profile 中扫码登录抖音和B站，并在 ZCode 官方 Bot Channel 中连接自己的微信；
- 逐字稿增强版尚未完成真实视频全链路验收，公开默认仍是不需要 SenseVoice 的标准版；
- 戏仿、夸张和反问尚未分别冻结质量样本；20 人体验、真实平台登录失效和付费服务中断的长时间验收仍未完成；
- 仅支持抖音/B站普通单视频，不支持合集、直播、番剧、互动视频或 DRM 内容；
- 不提供公共 Cookie、公共机器人、云端账号、支付或托管处理。

## 安全提示

只使用自己的 Kimi Key 与平台账号。不要向 Issue、聊天截图或日志粘贴 Key、Cookie、Bearer 或签名媒体地址。下载后请核对同一 Release 中的 `SHA256SUMS`。
