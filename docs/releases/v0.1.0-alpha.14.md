# 视知库 v0.1.0-alpha.14

本版修复 `alpha.12`/`alpha.13` 在 ZCode 官方 Bot 通道处理 20–30 分钟抖音或 B 站视频时，会在 Kimi 视频分析即将完成前被 20 分钟 MCP 边界强制中断的问题。

## 修复

- ZCode 受管 MCP 工具调用上限由 20 分钟提高到 60 分钟，覆盖下载、代理准备和一次 Kimi 视频分析；
- Kimi 上游等待上限由 20 分钟提高到 45 分钟；
- “安装 / 修复本机”会将旧安装器写入的 20 分钟默认值安全迁移，保留 Vault、档位、路径、注释和未知未来字段；
- 只有受管的“视知库助手”工作区会自动升级 MCP 配置，不修改其他 ZCode 工作区。

## 安全与费用边界

- 没有增加 Kimi 调用次数，单个逻辑任务仍最多发起一次完整视频分析；
- 延长的是本机等待边界，不代表额外付费或自动重试；
- 修复后需完全重启 ZCode，使新的工作区 MCP 配置生效。
