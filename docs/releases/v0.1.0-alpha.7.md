# 视知库 v0.1.0-alpha.7

这是面向公开下载的 Windows x64 安全修复版技术预览。它继续验证“微信发送抖音/B站单视频链接，在用户自己的电脑上生成结构化 Markdown 并写入 Obsidian”的本地优先链路。它不是稳定版、托管服务或公共微信机器人。

## 本版修复

- Windows 安装、修复和配置更新现在会将视知库私有配置、运行状态与 ZCode 模型配置 ACL 收紧为当前用户、SYSTEM 和本机管理员可访问；
- 收紧过程只处理文件权限，不读取、输出或改写 API Key 内容；
- ZCode 模型配置的恢复副本使用同一权限规则，避免备份成为旁路泄露点；
- 安装器修复流程新增零付费权限检查，不要求 Coding Plan，也不发起视频分析。

## 验收证据

- 121 项核心自动测试覆盖跨平台私有权限、真实 Windows 3.11/3.12 ACL 集成、Windows 失败阻断、ZCode 权限修复的脱敏返回和原有管线回归；
- ROG Windows 11 实机先在临时文件演练，再对真实配置执行修复；修复后额外本地组不再具有读权限，ZCode 仍能识别 4 个可用模型通道并保持运行；
- 全过程未读取凭据内容、未输出 Secret、未调用付费模型。

## 已知限制

- 安装包尚未代码签名，Windows SmartScreen 可能显示“未知发布者”；
- 首次准备仍需联网下载依赖，建议预留约 1–2 GB 空间和 10–30 分钟；
- 用户必须亲自在专用 Firefox Profile 中扫码登录抖音和B站，并在 ZCode 官方 Bot Channel 中连接自己的微信；
- 逐字稿增强版尚未完成真实视频全链路验收，公开默认仍是不需要 SenseVoice 的标准版；
- 戏仿、夸张和反问尚未分别冻结质量样本；20 人体验、真实平台登录失效和付费服务中断的长时间验收仍未完成；
- 仅支持抖音/B站普通单视频，不支持合集、直播、番剧、互动视频或 DRM 内容。

## 安全提示

只使用自己的 Kimi Key 与平台账号。不要向 Issue、聊天截图或日志粘贴 Key、Cookie、Bearer 或签名媒体地址。下载后请核对同一 Release 中的 `SHA256SUMS`。
