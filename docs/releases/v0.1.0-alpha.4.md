# 视知库 v0.1.0-alpha.4

这是面向公开下载的 Windows x64 技术预览版。它把干净普通账户上的图形安装验收结果固化进安装包，继续验证“微信发送抖音/B站链接，自动生成结构化 Markdown 并写入 Obsidian”的本地优先链路。它不是稳定版或云端托管服务。

## 本版改进

- 修复新建 Windows 普通账户无法解析系统 `winget` 的问题；
- Firefox 安装增加软件源刷新、重试和 Mozilla 官方下载降级，避免单次 `winget` 源波动中断整套安装；
- Obsidian 改为通过 Microsoft Store 安装，减少第三方下载失败；
- FFmpeg 改用体积更小的 Essentials 构建；
- 弱网依赖下载最长等待时间提高到 30 分钟；
- 保留隔离 Python、专用 Firefox Profile、默认中文 Vault、ZCode 专用工作区和单一 MCP；
- 继续默认关闭逐字稿、关闭原视频永久保存，并把 Kimi Key 存入 Windows Credential Manager。

## 验收证据

- 干净 Windows Runner 覆盖首次安装、原地修复、默认安全卸载、重装和受管私有目录卸载；
- Windows 11 ROG 新建标准账户 `VTOAcceptance`，只通过图形安装器完成准备，不克隆仓库、不打开终端；
- 图形流程创建隔离运行时、无 Secret 配置、空中文 Vault、专用 ZCode 工作区、单一 MCP 和 `VideoToObsidian` Firefox Profile；
- 抖音小视频与 B站 37 分钟长视频已在 ROG 完成真实下载、K2.7 单次分析和 Obsidian 入库；
- ZCode 官方微信 Bot 已完成免费体检和双平台输入验收。

## 已知限制

- 安装包尚未代码签名，Windows SmartScreen 可能显示“未知发布者”；
- 首次准备仍需联网下载依赖，建议预留约 1–2 GB 空间和 10–30 分钟；
- 用户必须亲自在专用 Firefox Profile 中扫码登录抖音和B站，并在 ZCode 官方 Bot Channel 中连接微信；
- 临时普通账户上的全新抖音/B站扫码尚未单独验收；
- B站短视频、总结质量固定集与规模稳定性尚未完成；
- 仅支持普通单视频，不支持合集、直播、番剧、互动视频或 DRM 内容；
- 不提供公共 Cookie、公共机器人、云端账号、支付或托管处理。

## 安全提示

只使用自己的 Kimi Key 与平台账号。不要向 Issue、聊天截图或日志粘贴 Key、Cookie、Bearer 或签名媒体地址。下载后请核对同一 Release 中的 `SHA256SUMS`。

## 开始使用

安装、扫码、首次体检与失败恢复参见 [Windows 安装与扫码指南](https://github.com/cgmdeep/video-to-obsidian/blob/v0.1.0-alpha.4/docs/INSTALL_WINDOWS.md)。
