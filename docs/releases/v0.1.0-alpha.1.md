# 视知库 v0.1.0-alpha.1

这是第一个面向公开下载的 Windows x64 技术预览版。它用于验证“微信发送抖音/B站链接，自动生成结构化 Markdown 并写入 Obsidian”的本地优先链路，不是稳定版或云端托管服务。

## 已实现

- 单个 `VideoToObsidian.Setup.exe`，无需预装 .NET；
- 自动准备隔离 Python 运行时、Obsidian、Firefox、ffmpeg、默认 Vault 与 ZCode 专用工作区；
- Kimi API Key 保存到 Windows Credential Manager，不写入仓库、Vault 或诊断报告；
- ZCode 官方微信 Bot Channel 作为微信输入入口；
- 抖音与B站普通单视频路由，默认 K2.7，精确短语“使用K3深度分析”才启用 K3；
- 默认不生成逐字稿、不永久保存原视频；
- 跨进程任务锁、检查点复用、Kimi 尝试账本和平台受控降级；
- Windows 超时会终止完整子进程树，`command_timeout` 不允许机器人盲目重试；
- 结构化中文 Markdown 原子写入 Obsidian Vault。

## 已有验收

- 83 项本地测试（含发布版本一致性测试）；
- Linux/Windows、Python 3.11/3.12 CI；
- 干净 Windows Runner 免费准备验收；
- ROG Windows 11 实机抖音下载、Kimi K2.7 单次分析与 Obsidian 入库；
- ROG ZCode 官方微信 Bot 免费“检查系统”；
- Windows 父子进程超时整组清理，无付费模型调用。

## 已知限制

- 安装包尚未代码签名，Windows SmartScreen 可能显示“未知发布者”；
- B站付费真实闭环、20～30 分钟长视频固定集、反讽/引用固定集尚未完成；
- 安装器尚未注册到 Windows“已安装的应用”，卸载使用仓库中的安全脚本；
- 处理时 Windows 电脑与 ZCode 需要保持运行；
- 仅支持普通单视频，不支持合集、直播、番剧、互动视频或 DRM 内容；
- 不提供公共 Cookie、公共机器人、云端账号、支付或托管处理。

## 安全提示

只使用自己的 Kimi Key 与平台账号。不要向 Issue、聊天截图或日志粘贴 Key、Cookie、Bearer 或签名媒体地址。下载后请核对同一 Release 中的 `SHA256SUMS`。
