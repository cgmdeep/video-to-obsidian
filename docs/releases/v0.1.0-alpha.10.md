# 视知库 v0.1.0-alpha.10

`v0.1.0-alpha.10` 是 Windows x64 未签名公开 Alpha，补齐首次配置完成后的最后一公里。

## 本次修复

- 安装或修复成功后，自动安全登记并打开新建的 Obsidian 知识库。
- 自动使用 `文档\\视知库助手` 作为启动参数打开 ZCode 专用工作区。
- 保存 Kimi Key 并补齐 ZCode 模型后再次执行上述打开动作，覆盖“先准备环境、后安装 ZCode”的常见顺序。
- 自动打开失败不会回滚已完成的安装；状态区会明确提示使用现有手动按钮重试。
- 延续 `alpha.9` 对故障 Microsoft Store 源的隔离：依赖操作固定使用社区 `winget` 源，并复用已有 FFmpeg。

## 已知限制

- 安装器仍未进行商业代码签名，Windows SmartScreen 可能提示未知发布者。
- ZCode、Obsidian 或其窗口管理策略可能使新窗口停留在后台；安装器保留“在 ZCode 中打开”和“打开 Obsidian 知识库”按钮。
- 用户仍需自行填写 Kimi API Key，并扫码登录自己的视频平台和 ZCode 官方微信 Bot Channel。
- macOS 公开版、游客实时体验、支付与用户控制台不属于本版本。
