# 官网与产品口径基线

更新时间：2026-09-29。官网、演示、安装文档和比赛材料应以本文件为准；规划功能不得写成已经实现。

## 当前真实产品

```text
用户自己的微信
→ ZCode 官方微信 Bot Channel
→ 用户 Windows 电脑上的“视知库助手”工作区
→ video-to-obsidian 本地 MCP
→ Kimi 视频分析
→ 本地 Obsidian Vault
```

- 企业微信客服线路已停用，不是当前入口。
- 微信能力由 ZCode 官方 Bot Channel 提供，不使用个人微信 Hook。
- 当前比赛版和开源版不依赖项目方中央服务器。
- ZCode、电脑和本地 MCP 承担运行；Obsidian 是最终知识库。
- 用户使用自己的 Kimi API Key、抖音账号、B站账号和微信。
- Coding Plan 不是必需条件；ZCode 仍需一个可用模型通道。

## 用户下载安装的内容

下载物名称：`VideoToObsidian.Setup.exe`。

它是 Windows x64 单文件安装与连接向导，不是 Obsidian 插件，也不是独立桌面知识库。安装器会准备 Python 隔离环境、Firefox、Obsidian、ffmpeg、专用 Vault 和 ZCode 工作区。ZCode 本体通过其官方下载页安装。

当前构建约 68 MB；正式发布必须在 Release 页面同时提供准确字节数和 SHA256。Alpha 尚未代码签名，必须明确提示 SmartScreen 风险。

## 普通用户路径

```text
官网下载一个 EXE
→ 安装 / 修复本机
→ 输入自己的 Kimi Key
→ 扫码登录抖音/B站
→ 在 ZCode 打开“视知库助手”并扫码连接微信
→ 微信发送完整视频分享文本
→ Markdown 自动写入 Obsidian
```

默认不生成逐字稿、不永久保存原视频。SenseVoice、NAS、Tailscale、GPU 和闲置服务器全部是可选增强，不得列为基础要求。

## 官网可以写的内容

- 抖音和B站普通单视频路由；
- 默认 K2.7，精确短语“使用K3深度分析”才启用 K3；
- Kimi 直接看视频并写正式中文笔记；
- Obsidian 本地 Markdown 入库；
- 用户可用自然语言调整长期总结偏好；
- 安装器、CI、安全扫描和无费用模拟测试已经存在。

官网必须继续标注 Alpha：干净 Windows Runner 已完成安装、原地修复、安全卸载、重装和受管私有目录清理验收；独立 Windows 11 ROG 已完成抖音小视频和 B站 37 分钟长视频的真实下载、付费 K2.7 单次分析与 Obsidian 入库，ZCode 官方微信 Bot 也已完成免费体检和双平台输入验收。B站短视频、总结质量固定集与规模稳定性仍未完成公开验收。

## 官网暂时不能写的内容

- “下载 Obsidian 插件”或“社区插件商店安装”；
- 企业微信客服、公众号、小程序或项目方公共机器人；
- 无需保持电脑/ZCode运行；
- 云端账号、网页任务中心、支付、卡密、套餐或陌生用户公开提交；
- 已签名、生产可用、零故障、完全自动；
- 固定每条视频价格。

比赛官网可以公开首页、真实案例、安装说明、技术证据和隐私说明，但不开放陌生用户任意提交付费任务。域名与静态官网可以先部署在 GitHub Pages；域名不影响本地产品和 ZCode 微信入口。
